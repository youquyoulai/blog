这道题我第一眼没反应过来。往年单选压轴基本是函数导数极值那一套，它偏要换个玩法，把空间点集和概率期望揉到一起，抽象得很，有人干脆叫它"微型科研"。

题目是这样：

设 $U = \{(x_1, x_2, x_3) \mid x_i \in \{-2, -1, 1, 2\}\}$，$P = (1, 1, 1)$。从 $U \setminus \{P\}$ 中随机取 1 个点 $A$，定义随机变量 $X(A) = x_1 + x_2 + x_3$（其中 $A = (x_1, x_2, x_3)$），则 $X$ 的数学期望为（ ）

A. $-\dfrac{1}{21}$

B. $\dfrac{1}{63}$

C. $0$

D. $\dfrac{2}{21}$

**答案：A**

说它"反套路"，是说命题人不想考你硬算，而是考在陌生情境下能不能停下来想一想。硬算其实烦得很——要穷举 63 个点取值再算概率；可只要看穿集合 $U$ 的**中心对称性**，计算立马塌下来一大半。新课标讲建模素养，概率统计早不是骰子摸球那点事，往抽象里走，这道题就是个信号：重基础、重思维、反套路。

据考后统计，这题错误率超过 65%，正确率不足 30%，是全卷客观题最大的失分坑。中等生耗了时间还拿不到分，正好把中等生和尖子生拉开。

## 考查知识点

| 知识模块 | 具体内容 | 考查深度 |
|---------|---------|---------|
| **集合** | 空间点集的定义、集合补集运算 | 中 |
| **排列组合** | 分类计数原理、分步计数原理 | 高 |
| **概率** | 等可能概率模型、古典概型 | 高 |
| **离散随机变量** | 随机变量的定义、可能取值 | 中 |
| **数学期望** | $E(X) = \sum x_i \cdot p_i$ 的计算 | 高 |
| **对称性思想** | 中心对称在期望计算中的应用 | 极高 |
| **空间坐标** | 三维坐标、点与坐标的对应 | 基础 |

**1. 空间点集 $U$ 的结构**

$U$ 由 $-2, -1, 1, 2$ 四个数中任取三个（可重复）组成三维坐标，共 $4^3 = 64$ 个点。去除 $P = (1,1,1)$ 后，样本空间 $\Omega = U \setminus \{P\}$ 共 63 个元素，每个点被等可能地取到。

**2. 随机变量 $X(A)$ 的含义**

$X(A) = x_1 + x_2 + x_3$，即将三维坐标的三个分量相加，取值范围从 $-6$（$(-2,-2,-2)$）到 $6$（$(2,2,2)$）。

**3. 期望的线性可加性**

$E(X) = \sum_{A \in \Omega} X(A) \cdot P(A)$，由于等可能取值，$E(X) = \dfrac{1}{63}\sum X(A)$。

## 解题方法

### 方法一：暴力枚举法（直接法）

**核心思路**：穷举 $X$ 的所有可能取值，计算对应的概率，再求期望。

**步骤框架**：

1. **分析 $X$ 的可能取值**：

   三坐标均取自 $\{-2, -1, 1, 2\}$，分三种情况：

   | 类型 | 条件 | 典型例子 | 取值范围 |
   |-----|------|---------|---------|
   | 三同 | $x_1 = x_2 = x_3$ | $(2,2,2)$ | $\pm 6$ |
   | 两同一异 | 恰有两个分量相同 | $(2,2,1)$ | $\pm 5, \pm 4, \pm 3$ |
   | 三异 | 三个分量互不相同 | $(2,1,-1)$ | $\pm 3, \pm 2, \pm 1, \pm 3$ |

2. **逐类统计频数**：

   | $X$ 的取值 | 对应点的个数 | 概率 |
   |-----------|------------|------|
   | $6$ | $1$ (即$(2,2,2)$) | $1/63$ |
   | $-6$ | $1$ (即$(-2,-2,-2)$) | $1/63$ |
   | $5$ | $3$ | $3/63$ |
   | $-5$ | $3$ | $3/63$ |
   | $4$ | $3$ | $3/63$ |
   | $-4$ | $3$ | $3/63$ |
   | $3$ | $3$ | $3/63$ |
   | $-3$ | $4$（含 $(1,1,1)$ 已排除后为 $3+1-1=3$...） | 需仔细计算 |
   | ... | ... | ... |

   **注意**：由于 $P(1,1,1)$ 被排除（$X = 3$），导致 $X = 3$ 与 $X = -3$ 的概率出现**不对称**。

3. **计算期望**：

   利用正负对称，$E(X)$ 仅由不对称部分贡献。

**评价**：思路直接但计算量大、易出错，在考场高压环境下不适合作为首选方案。

### 方法二：对称性分析法（巧解）—— 推荐方法

**核心思路**：利用集合 $U$ 关于原点的中心对称性，大幅简化期望计算。

**步骤框架**：

1. **观察对称性**：

   对于 $U$ 中任意一点 $A = (x_1, x_2, x_3)$，其关于原点的对称点 $-A = (-x_1, -x_2, -x_3)$ 也在 $U$ 中（因为 $-2, -1, 1, 2$ 关于原点对称）。

   且 $X(-A) = -x_1 - x_2 - x_3 = -X(A)$。

2. **配对求和**：

   将 $U$ 中所有点按 $(A, -A)$ 配对，每对的 $X$ 值之和为 $0$。

   因此 $\sum_{A \in U} X(A) = 0$。

3. **处理排除点**：

   从 $U$ 中去掉 $P = (1,1,1)$ 后：

   $$\sum_{A \in \Omega} X(A) = \sum_{A \in U} X(A) - X(P) = 0 - 3 = -3$$

4. **计算期望**：

   $$E(X) = \frac{-3}{63} = -\frac{1}{21}$$

**评价**：充分利用对称性，仅需三步即可得出答案，完美体现"多想少算"的命题意图。

### 方法三：期望线性可加法

**核心思路**：利用期望的线性性质 $E(X) = E(X_1) + E(X_2) + E(X_3)$，分别计算每个坐标分量的期望。

**步骤框架**：

1. **分解**：$X(A) = x_1 + x_2 + x_3$，设 $X_i$ 为第 $i$ 个坐标分量。

2. **计算每个分量的期望**：

   以 $x_1$ 为例：在 $U$ 中 $-2, -1, 1, 2$ 各出现 $4^2 = 16$ 次，$\sum x_1 = 16 \times (-2 - 1 + 1 + 2) = 0$。

   去掉 $P(1,1,1)$ 后，$\sum x_1 = 0 - 1 = -1$，故 $E(X_1) = -1/63$。

   同理 $E(X_2) = E(X_3) = -1/63$。

3. **利用线性可加性**：

   $$E(X) = E(X_1) + E(X_2) + E(X_3) = \frac{-1}{63} \times 3 = -\frac{1}{21}$$

**评价**：掌握"期望的线性可加性"的考生可以最快进入状态，是一种高效且不易出错的解法。

## 难度与失分

| 维度 | 评价 |
|-----|------|
| 知识门槛 | 低——所有知识点不超纲，均为必修内容 |
| 计算门槛 | 中高——暴力枚举计算量大 |
| 思维门槛 | 极高——需要自主构建概率模型、洞察对称性 |
| 综合难度 | ★★★★（全卷单选最难） |

掉坑的原因，我琢磨着主要有几条：题干信息量大，学生一时半会提取不出有效条件；建模能力弱，不知道从哪下手；选了硬算的，在 63 个点里数着数着就漏了或重了；还有一大批是根本没想到用对称性，闷头硬算把时间搭进去。考后数据也印证了：正确率不足 30%，中等生普遍耗了 3 到 5 分钟还定不下来，尖子生靠对称性一两分钟就完事。

## 备考建议

平时练题，对称性这把钥匙得常备：中心对称配对的，轴对称、周期性的，都值得多练。期望的线性可加性更是核心工具，分量不独立时也照样成立，得通过典型题练到顺手。

更重要的是养成"多想少算"的习性——碰到看着复杂的计算题，先停一下，看有没有对称、周期、递推这类结构；先整体后局部。一题多解也别嫌烦，把暴力法和巧解法比一比，就明白思维值钱在哪。

阅读理解、建模能力也得专门练：把大段文字翻译成数学表达式，从一堆信息里捞关键的、扔干扰的。跨模块融合的题（空间加概率、向量加数列、几何加复数）多见见，别一看到陌生壳子就慌。

考场上时间得掐紧：单选压轴别超过 3 分钟，一分钟没头绪就先标记跳过去，回来再算。一道选择题不值得把整张卷子拖垮。

## 说到底

2026 新高考 I 卷第 8 题是道高质量的选择题——反传统、反套路，把空间点集和概率期望捏到一起；门槛低、思维高，知识点全不超纲，区分度却极强；暴力法能算但笨，巧解法干净利落。它是新高考"反套路、重思维"最直白的样本，释放的信号很清楚：以后高考数学不奖"背题型"的，只偏爱"会想、能变通"的。
