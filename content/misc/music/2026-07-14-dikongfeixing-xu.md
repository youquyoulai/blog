2020年，郑钧借着《我是唱作人》第二季，连着抛出《低空飞行》和《继续挥舞》两首。算算，离他1994年凭《赤裸裸》横空出世，已经过去二十多年。当年的摇滚小子，到了知天命的岁数。可这两首没半点暮气——一个内省、和解，一个反抗、坚守，恰好是郑钧中年创作的两面。

先说《低空飞行》。2020年4月28日在节目第二期头回唱，词曲都是郑钧自己，编曲Hans陈思翰，音乐总监谭伊哲，混音林梦洋。数字单曲4月24日由郑钧工作室先发，到2022年3月11日才在QQ音乐放出录音室版和MV。一首复古摇滚，用了6415的和声走向，在5级和弦上靠旋律音和弦构成Gadd9的编曲设计，简约却不空。郑钧说灵感是开车时得的——难怪歌里那股"在路上"的流动感，不是摇滚青年式地狂奔，是一个什么都经历过了的人，匀速往前时对自己的打量。

> 感觉像在低空飞行 / 在人群之中从容穿梭 / 享受着缺氧的快乐 / 躲避着猎人的捕捉
>
> 积攒了一生的财宝 / 在不经意间被偷走 / 他焦急的四处寻找 / 忽略了枪响的信号
>
> 有人也许能夺走我的一切 / 但无法夺走我的勇气 / 有人也许能摧毁你的世界 / 但无法摧毁你留下的美丽
>
> 总是还有一线希望 / 让人盼望着奇迹 / 天空是多么自由 / 可我已经无力停留
>
> 越过了一生的城池 / 尝尽了人间冷暖 / 从来都不曾回头 / 永远也不挽留
>
> We stay hungry / We stay thirsty / We stay foolish / But we all wanna be free

这歌在节目里帮郑钧赢了转型摇滚的GAI，话题还上了热搜。豆瓣8.9分（625人评）。有乐评说它"再次用摇滚精神唱出平和的生活态度，一开口熟悉的郑钧又回来了"；有网友直呼是"郑钧近几年最好的作品，找到了《赤裸裸》的感觉"。还有人管它叫"复工摇滚"——"人间冷暖常在，有人会在不经意间夺走我们的一切，但是我们的勇气是他们不能夺走的"。媒体说郑钧是用自己的状态借摇滚说话："不慌不忙，不争不抢，老炮儿想用作品告诉大家，'不急'的状态，才能有属于自己的美丽。"2020年那个特殊的年头，这种"不慌不忙"恰好戳中许多人想重新理顺生活节奏的心思。

另一首《继续挥舞》，5月15日节目第五期亮相，同样词曲郑钧、编曲Hans陈思翰。跟《低空飞行》的克制相反，这是一声"朋克式的呐喊"——电吉他轰鸣、节奏澎湃，被说成"节目截止到现在最令人血压上升、激动不已的曲目之一"。郑钧在节目里透底，这歌是写给从前一哥们儿的，"家里有矿还很帅"，感叹年轻时光顾着说些"混蛋和放荡的话"，没认真谈过恋爱。本是一时兴起，落到作品里却升成了更普遍的东西：密集的排比，"梦想只剩欲望""爱情只剩捆绑"，直戳现代人的精神困局。有评论说它"主流得像一首90年代初的内地摇滚"——这种复古不是守旧，是在精神碎片化的年头，把摇滚最本真的力气捡回来。

> 生活总是让人猝不及防 / 最无耻的人最坦荡 / 你渴望拥有成功和胜利 / 却为何没有说出 / 一句真话的勇气
>
> 每天都在疯狂的东奔西忙 / 为掩盖内心的恐慌 / 每个人都在审判别人的肮脏 / 每个人都觉得自己很冤枉
>
> 就算梦想只剩下欲望 / 爱情只剩下捆绑 / 能说的话只剩下废话 / 我们还是要继续奔跑啊
>
> 我觉得自己总是一厢情愿 / 有时候让人生无可恋 / 你觉得跟生活势不两立 / 你无法饶恕你自己
>
> 总是说些混蛋而放荡的话 / 因为你从来没有爱过吧 / 你其实并不真的需要我 / 你只是需要占有我的快乐
>
> 不管身体被困在何方 / 心永远要流浪 / 手中的旗帜就算百孔千疮 / 我还是要继续挥舞它
>
> 如今你已经被彻底驯化 / 在马戏团里取悦大家 / 生活总是想让人跪地求饶 / 可我还是忍不住想笑

豆瓣9.0分（218人评），比《低空飞行》还高一分。乐评说它"歌词直白有力，作品有深度，有自省，也有尖锐、引人思考的地方"。有听众听出了"一个已经屈服于生活的人，对一些难再付诸行动的追求的渴望——即便对外满不在乎，内心的小旗帜却还时而乘风挥舞"；也有人听出了"过去那个傲娇唯我独尊的郑钧"，说它"有态度和情怀"。"手中的旗帜就算百孔千疮，我还是要继续挥舞它"这句话被到处引，成了坚守理想主义的宣言。2022年的专辑《两只口罩》收了它，专辑简介里就写着"听到了对理想主义的坚持"。

把两首摆一块儿看，对照得巧。《低空飞行》是"低空"的、从容的，"享受着缺氧的快乐"；《继续挥舞》是"百孔千疮"的、疯劲的，"还是要继续挥舞它"。一个向下收，一个向上扬。情绪上，《低空飞行》满是和解——"从来都不曾回头，永远也不挽留"；《继续挥舞》满是不甘——"生活总是想让人跪地求饶，可我还是忍不住想笑"。可骨子里殊途同归。郑钧研习佛法多年，跟当年那个桀骜的自己和解了不少，但"变化的是与世界相处的形式，而非理想主义者的本质"。《低空飞行》的从容不是妥协，是更高一层的坚持——不必嘶吼来证明什么；《继续挥舞》的挥舞也不是徒劳，是认清现实还不愿松手。

有评论说得好："老音乐人最难得的，是对当下仍然有知觉。"52岁的郑钧没装自己还是唱《赤裸裸》的少年，也没丢掉摇滚最核心的那点精神——对真实的追求、对自由的向往、对不公的反抗。从第二期《低空飞行》到第五期《继续挥舞》，他是一步步找回"黄金年代的范儿"的：先松弛下来，再全情投入。先跟自己和解，再跟世界较量。

这两首，一首教你在人群里低空从容地穿，一首教你想挥舞就挥舞，哪怕旗子已经百孔千疮。不矛盾，是一个成熟的人面对世界的两种聪明：知道什么时候该放，也知道什么东西绝不能放。
