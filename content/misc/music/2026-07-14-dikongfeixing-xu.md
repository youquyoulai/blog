# 郑钧《低空飞行》与《继续挥舞》综合解读

## 引言

2020年，郑钧以音乐竞演节目《我是唱作人》第二季为契机，接连推出了《低空飞行》与《继续挥舞》两首作品。此时距离他凭借《赤裸裸》横空出世的1994年[reference:0]，已过去二十余年。当年的摇滚青年，已然步入知天命之年。然而这两首歌并未流露出任何暮气——它们以截然不同的姿态，共同构成了郑钧中年创作的一体两面：一面是内省与和解，一面是反抗与坚守。

## 一、《低空飞行》：从容穿梭的中年独白

### 歌词全文

> 感觉像在低空飞行 / 在人群之中从容穿梭 / 享受着缺氧的快乐 / 躲避着猎人的捕捉
>
> 积攒了一生的财宝 / 在不经意间被偷走 / 他焦急的四处寻找 / 忽略了枪响的信号
>
> 有人也许能夺走我的一切 / 但无法夺走我的勇气 / 有人也许能摧毁你的世界 / 但无法摧毁你留下的美丽
>
> 总是还有一线希望 / 让人盼望着奇迹 / 天空是多么自由 / 可我已经无力停留
>
> 越过了一生的城池 / 尝尽了人间冷暖 / 从来都不曾回头 / 永远也不挽留
>
> We stay hungry / We stay thirsty / We stay foolish / But we all wanna be free[reference:1]

### 创作背景与音乐特点

《低空飞行》是郑钧为参加《我是唱作人》第二季创作的竞演作品，2020年4月28日在节目第二期首次演唱[reference:2][reference:3]。歌曲由郑钧独立完成词曲创作，编曲由Hans陈思翰操刀，音乐总监为谭伊哲，混音由林梦洋负责[reference:4][reference:5]。该曲的数字单曲于2020年4月24日由郑钧工作室发行[reference:6]，2022年3月11日通过QQ音乐平台正式发布录音室版本及配套MV[reference:7]。

从音乐风格来看，《低空飞行》是一首复古摇滚作品[reference:8]。歌曲采用6415和声进行，在5级和弦处通过旋律音与和弦构成Gadd9的编曲设计，呈现出简约而不失层次感的音乐架构[reference:9]。这种极简的创作手法，恰恰与歌曲所要传达的“从容”与“不争”形成呼应。舞台版本相较试音间小样，增加了转调等复杂编曲元素[reference:10]，但在整体气质上始终保持克制——没有嘶吼，没有炫技，有的只是一个中年男人在低空掠过的平静叙事。

关于创作灵感，郑钧曾透露这首歌是他在开车时获得灵感的[reference:11]。这或许解释了歌曲中那种“在路上”的流动感——不是摇滚青年式的狂奔，而是一个经历过一切的人，在匀速前行中的自我观照。

### 乐评与公众评价

《低空飞行》在《我是唱作人2》第二期中，帮助郑钧战胜了转型摇滚风格的说唱歌手GAI[reference:12][reference:13]，相关话题也登上热搜[reference:14]。在豆瓣音乐上，该歌曲获得8.9分的高分（625人评价）[reference:15]。

乐评界对这首歌给予了高度评价。有评论指出，这首复古摇滚“再次用摇滚精神唱出平和的生活态度，一开口熟悉的郑钧又回来了”[reference:16]。有网友称其为“郑钧近几年最好的作品，找到了《赤裸裸》的感觉”[reference:17]。更有人将其称为“复工摇滚”——“人间冷暖常在，有人会在不经意间夺走我们的一切，但是我们的勇气是他们不能夺走的”[reference:18]。

媒体评论认为，在这首《低空飞行》里，郑钧是在用自己的切身经历和真实状态，借摇滚乐来做出最合适的表达——“不慌不忙，不争不抢，老炮儿想用作品告诉大家：'不急'的状态，才能有属于自己的美丽”[reference:19]。音乐评论还指出，该作品通过“中年人”视角展现诗性表达，以极简创作手法对抗浮躁的社会情绪[reference:20]。

有网友的解读尤为精辟：“《低空飞行》是一首最适合当下这个时期的歌曲”[reference:21]。在2020年那个特殊的年份，这首歌所传递的“不慌不忙”的生活态度，恰好契合了无数人对重新审视生活节奏的内在需求。

## 二、《继续挥舞》：百孔千疮的理想主义战歌

### 歌词全文

> 生活总是让人猝不及防 / 最无耻的人最坦荡 / 你渴望拥有成功和胜利 / 却为何没有说出 / 一句真话的勇气
>
> 每天都在疯狂的东奔西忙 / 为掩盖内心的恐慌 / 每个人都在审判别人的肮脏 / 每个人都觉得自己很冤枉
>
> 就算梦想只剩下欲望 / 爱情只剩下捆绑 / 能说的话只剩下废话 / 我们还是要继续奔跑啊
>
> 我觉得自己总是一厢情愿 / 有时候让人生无可恋 / 你觉得跟生活势不两立 / 你无法饶恕你自己
>
> 总是说些混蛋而放荡的话 / 因为你从来没有爱过吧 / 你其实并不真的需要我 / 你只是需要占有我的快乐
>
> 不管身体被困在何方 / 心永远要流浪 / 手中的旗帜就算百孔千疮 / 我还是要继续挥舞它
>
> 如今你已经被彻底驯化 / 在马戏团里取悦大家 / 生活总是想让人跪地求饶 / 可我还是忍不住想笑[reference:22][reference:23]

### 创作背景与音乐特点

《继续挥舞》同样诞生于《我是唱作人》第二季，于2020年5月15日在节目第五期中首次亮相[reference:24][reference:25]。歌曲由郑钧独立完成词曲创作，编曲仍由Hans陈思翰操刀[reference:26]。与《低空飞行》的克制不同，《继续挥舞》是一首“朋克式的呐喊”[reference:27]——电吉他的轰鸣和澎湃节奏贯穿全曲[reference:28]，被评论者称为“节目截止到现在最令人血压上升、激动不已的曲目之一”[reference:29]。

郑钧在节目中透露，这首歌曲其实是写给以前的哥们——“家里有矿还很帅”，感叹年轻的时候没有认真谈过恋爱，总是说一些“混蛋和放荡的话”[reference:31]。这个看似随意的创作动因，却在最终的作品中升华为更具普遍性的表达。歌曲采用密集的排比句式构建文本，通过“梦想只剩欲望”“爱情只剩捆绑”等意象直指现代社会的精神困境[reference:32]。

从音乐形态来看，《继续挥舞》的“闷音快速下拨特别的流行朋克，过门儿的鼓点儿切分加分”[reference:33]，被形容为“像在赌咒”的主歌与“像在还愿”的副歌形成鲜明对比[reference:34]。有评论认为，这首歌“主流得像是一首90年代初的内地摇滚”[reference:35]——这种“复古”恰恰不是守旧，而是在一个精神碎片化的时代，重新拾起摇滚乐最本真的力量。

### 乐评与公众评价

《继续挥舞》在豆瓣音乐上获得了9.0分的高分（218人评价）[reference:36]，略高于《低空飞行》。乐评人指出，这首歌“歌词直白有力，作品有深度，有自省，也有尖锐、引人思考的地方”[reference:37]。

有评论者从个人角度解读：“我从这首歌里听出了一个已经屈服于生活中的人对于一些已经难以付诸实际行动的追求的渴望，即时对外表达出一种满不在意，但内心的小旗帜却还时而乘风挥舞。这种状态很容易让人产生共情”[reference:39]。另一位评论者写道，这首歌“看到了过去那个傲娇唯我独尊的郑钧，所以是一首比较有态度和情怀的歌曲”。

《继续挥舞》的核心意象——“手中的旗帜就算百孔千疮，我还是要继续挥舞它”——被广泛引用为对理想主义坚守的宣言[reference:41][reference:42]。有评论认为，这首歌“延续了郑钧作品中批判现实与彰显摇滚精神的创作脉络”[reference:43]。在2022年发行的专辑《两只口罩》中，这首歌被收录其中，专辑简介中写道：“听到了对理想主义的坚持”[reference:44]。

## 三、对比与意义：同一枚硬币的两面

将《低空飞行》与《继续挥舞》并置审视，会发现它们构成了一组精妙的对照。

**在姿态上**，《低空飞行》是“低空”的、“从容”的，是“享受着缺氧的快乐”[reference:45]的自在；《继续挥舞》则是“百孔千疮”的、“疯狂”的，是“还是要继续挥舞它”[reference:46]的执拗。前者是向下的、收敛的，后者是向上的、张扬的。

**在情绪上**，《低空飞行》充满了和解的意味——“从来都不曾回头，永远也不挽留”[reference:47]；《继续挥舞》则充满了不甘——“生活总是想让人跪地求饶，可我还是忍不住想笑”[reference:48]。前者接受失去，后者拒绝投降。

**在精神内核上**，两首歌却殊途同归。正如有评论者指出，郑钧研习佛法多年，“与曾经那个桀骜不驯的自我和解了许多”。但“变化的是与世界相处的形式，而非理想主义者的本质”。《低空飞行》的“从容”并非妥协，而是一种更高层次的坚持——不再需要嘶吼来证明什么；《继续挥舞》的“挥舞”也并非徒劳，而是在认清现实之后依然选择不放手。

有评论者将这两首歌放在一起观察：“老音乐人最难得的，是对当下仍然有知觉”[reference:51]。《低空飞行》和《继续挥舞》之所以动人，正在于它们不是对过去的复刻，而是对当下的真诚回应。52岁的郑钧没有试图假装自己还是那个唱《赤裸裸》的少年，但他也没有放弃摇滚乐最核心的精神——对真实的追求、对自由的向往、对不公的反抗[reference:52]。

两首歌还共同体现了郑钧在《我是唱作人》节目中的创作状态：从第二期的《低空飞行》到第五期的《继续挥舞》，他在逐步找回“黄金年代的范儿”。正如节目观察者所言，“他逐渐地松弛下来，状态也更为投入”。这种从“松弛”到“投入”的演进，恰恰对应了两首歌的精神递进——先与自己和解，再与世界较量。

## 结语

《低空飞行》与《继续挥舞》是郑钧中年创作的双重奏。前者以内省的姿态完成了与过去的和解，后者以倔强的姿态宣告了对理想的不弃。它们共同回答了一个问题：一个曾经桀骜不驯的摇滚人，在走过半生之后，如何继续做自己。

答案就在这两首歌里——既可以“低空飞行”，在人群之中从容穿梭；也可以“继续挥舞”，哪怕手中的旗帜已经百孔千疮。这不是矛盾，而是一个成熟的人面对世界的两种智慧：知道什么时候该放，也知道什么东西绝不能放。

正如《低空飞行》中所唱：“有人也许能夺走我的一切，但无法夺走我的勇气”[reference:55]。也如《继续挥舞》中所宣告：“手中的旗帜就算百孔千疮，我还是要继续挥舞它”[reference:56]。勇气与旗帜，一个向内，一个向外，共同构成了郑钧在2020年这个特殊年份里，送给这个时代最真诚的礼物。
