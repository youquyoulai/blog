2019年，梁博以"失踪人口"的架势重回《我是唱作人》，甩出两首风格迥异却同样镇场的歌——《表态》和《出现又离开》。前者七分半，乐队化编配，宣示独立人格的坚守；后者六分多，抒情摇滚，吟的是缘起缘灭的释然。两首词曲编曲，都是梁博一人包办。

**《表态》**

《表态》用第二人称"你"展开：

> 你总是静静的期待 / 你总是面容不改 / 你总是相信会有一朵花开 / 你总是让人不爱
>
> 你总是有你的神态 / 你总是自成一派 / 你从来没什么迷人的身材 / 却有个不变的姿态
>
> 来 保持你现在 / 无视他存在 / 也别去炫耀你的光彩 / 对 重视你的心 / 这样我爱
>
> 那些不明白 / 就不要明白 / 你不能故意 / 为了谁失去自由自在
>
> 哦乖 我怕你会疼 / 怕你无奈 / 你就是有你的姿态 / 你就是面容不改
>
> 你是否看到身边的鲜花海 / 正向着天空在摇摆
>
> 来 保持你现在 / 无视他存在 / 也别去炫耀你的光彩 / 对 记得你的心 / 这样我爱
>
> 那些不明白还是不明白 / 你还是不会为了谁失去自由自在 / 哦 我想你明白
>
> 少年你和伙伴 / 一起走过时间海 / 你和他搂着肩 / 只是不再是小孩
>
> 几个人的感情 / 依然的热情澎湃 / 如果面对现在 / 依然表态 / 依然表态

这歌是梁博去录音棚的路上写的。他听着过去乐队的录音，看着街边形形色色的人，合着情绪的词就浮上来了，当天下午就成了。2019年4月12日，在爱奇艺《我是唱作人》第一期头回唱；2021年5月31日，作了声阔"降噪舱"的推广曲正式发。七分三十五秒，乐队化编配，弦乐是跟环球爱乐乐团合作的，鼓手祁大为、贝斯杜大鹏、键盘张效衡、吉他Misha Kalinin。

有唱作人直说这时长不是传统流行歌该有的。梁博回得硬气："这首歌别说是7分钟，就算是17分钟、70分钟，只要它好听，有内容，观众同样会喜欢。时代进步最大的表现，就是大众有了独立的判断。"知乎上有人评："鼓点让我跟着他点了七个分钟的头，曲十分上口，不傻嚎，不愤怒，就是告诉你一些事，歌词直接了当，不复杂，直抒胸臆。"也有人说词"太口水"，可更多人吃这一口直白有力。有乐评写："梁博终于塑造出独特的个人风格。《表态》虽然让人联想到《男孩》，但它所传达的却是对自我信念的坚守和勇气。这正是梁博风格的典范之作，带有90年代摇滚的怀旧风情，但他将其演绎得更加富有氛围感，更加精致时尚。"

梁博自己的阐释极精练："表态，并不是对别人表态。"他把这歌献给所有打拼的平凡人——"你的自信，你真正的光彩，你要表达给自己，而不是炫耀给别人。如果你从内心认可自己的生活，你根本没必要流俗或向别人解释，我是一个什么样的人。"饭桌上他更直："《表态》这首歌，是不屑于表态。"这句话点透了歌的核心悖论：真正的态度，不需要向任何人证明，保持自己，就是最有力的表达。"少年你和伙伴，一起走过时间海"一段，把个人的坚守延到了友情——那些一起走过青春的人，即便不再是小孩，那股热乎劲还在。说到底，这歌问的是：在众声喧哗里，怎么不被外界裹挟，守住内心的自由自在。

**《出现又离开》**

《出现又离开》用第一人称，讲一段从相遇到分开的感情：

> 我和你 本应该 / 各自好 各自坏 / 各自生活的自在 / 毫无关联的存在
>
> 直到你 出现在 / 我眼中 躲不开 / 我也占领你的心海 / 充实着你的空白
>
> 为何出现在彼此的生活又离开 / 只留下在心里深深浅浅的表白
>
> 谁也没有想过再更改 / 谁也没有想过再想回来 / 哦 我不明白
>
> 我和你 不应该 / 制造感觉 表达爱 / 试探未知和未来 / 相信那胡言一派
>
> 当天空暗下来 / 当周围又安静起来 / 当我突然梦里醒来 / 就等着太阳出来
>
> 为何出现在彼此的生活又离开 / 只留下在心里深深浅浅的表白
>
> 谁也没有想过再更改 / 谁也没有想过再想回来 / 哦 我不明白
>
> 我们紧紧相拥 / 头也不抬 / 因为不想告别 / 就悄然离开
>
> 不用认真的说 / 多舍不得你 / 每一个未来 / 都有人在
>
> 每一个未来 / 都有人在 / 那你无需感慨 / 我别徘徊
>
> 因为谁也没有想过再更改 / 谁也没有想过再想回来

2019年4月19日，《我是唱作人》第一季第二期首唱。说的是两个本不该有交集的人，相遇、相知、相爱，到最后分开。旋律暖，是一段曾爱上又不得不放的手，既是告别，也是祝福。2019年8月4日，梁博在爱奇艺尖叫之夜北京站唱了它；2021年，那英在《乘风破浪的姐姐2》里翻唱，把影响又扩了一圈。

豆瓣9.7分（2462人评），85.7%给了五星；到2024年，光网易云评论就破百万，是平台评论量最高的华语情歌之一。最被人念叨的，是开篇那支爱尔兰风笛，一响就把人拽进悠远哀伤里。有乐评写："爱尔兰风笛声起，万般回忆皆成诗。这首《出现又离开》现场版，已然超越了普通情歌的范畴，成为一场关于缘分与告别的音乐哲思。"有人嫌词像"白开水"、没文采，可更多人赏它的克制和真。一篇流传的乐评给它总结了"四好"：歌词好——故事性、画面感强；曲子好、配乐好——爱尔兰风笛添了宁静悠扬；唱得好——跟梁博本人气质浑然一体；留白好——长达两分多的器乐演奏，给情绪留了流淌的空间。有听众说它"像作文一样完整，像电影一样悠长"。全长近七分钟，梁博说"只有七分钟才能把话说完"。

这歌最值钱的，是给出了一种"体面"的分手叙事。当下的华语情歌，要么狗血撕逼的怨妇腔，要么无病呻吟的emo卖惨，它却通篇没有一句华丽的词，没有一句直白的"我爱你"，却写出了成年人面对离别时的释然和尊严。"谁也没有想过再更改，谁也没有想过再想回来"，跟多数情歌的挽留、悔恨正相反，是一种独立的自我和释然。结尾"每一个未来，都有人在"，是全曲的眼——爱的人未必走到最后，可自己不能放弃对将来的盼头。这句话，成了无数人失去后安慰自己、继续往前走的力量。往深里说，它也隐喻着梁博对音乐理想的死守——像"出现又离开"的过客，不肯向世俗妥协。

把两首放一块儿，统一在梁博一贯的音乐哲学里。《表态》朝外，处理"我怎么面对他人"——不被理解不解释，不被爱不迎合；《出现又离开》朝内，处理"我怎么面对失去"——爱过不纠缠，告别不徘徊。一刚一柔，一外一内。表达上，《表态》用"你"劝导，直接有力；《出现又离开》用"我"追问，温柔克制。两首都近七分钟，梁博认一个理：好音乐不嫌长，够的时长才能把话说完——在"快餐音乐"当道的年头，这份坚持格外金贵。

共通的内核，是梁博那句"创作就是赤裸的满足自我"。他不迎合市场、不讨听众好，只写自己真认的。如他所说："我不敢保证我的歌每个人都能喜欢，这也无所谓，但我不喜欢的歌，笃定别人也不会喜欢。"

《表态》是他向世界宣告独立人格的战书，《出现又离开》是他向过往深情的告别挽歌。两首加起来近十五分钟，却让无数人甘愿单曲循环。在这个追短平快的年代，梁博用他的"慢"和"长"证明：真诚的音乐自有其力量——不需向谁表态，也不怕谁离开。有评论说他的音乐是"冷调"的摇滚，没有嘶吼的批判，却用旋律的留白和歌词的棱角，筑起一种内敛的强度。这种内敛的强度，恰恰是这喧嚣时代最稀罕的品质。
